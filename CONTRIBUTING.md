# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your change: `git checkout -b my-change`
3. Make your changes and commit them with a clear message.
4. Push the branch to your fork: `git push origin my-change`
5. Open a pull request describing what you changed and why.

## Reporting Bugs

Open an issue and include:
- What you expected to happen
- What actually happened
- The inputs you used (principal, rate, time)
- Your browser and device

## Suggesting Enhancements

Open an issue describing the feature or improvement and why it would be useful.

## Code of Conduct

By contributing, you agree to follow this project's [Code of Conduct](CODE_OF_CONDUCT.md).
